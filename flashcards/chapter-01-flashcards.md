## Chapter 1: Machine Learning and Neural Network Fundamentals — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Training set vs validation set vs test set — what is the purpose of each? | Training: Fit model parameters (weights). Validation: Tune hyperparameters and detect overfitting during training. Test: Final evaluation, never touched until the end. Exam tip: Using test data during training/tuning invalidates your evaluation — this is a common exam trap scenario. |
| 2 | What are the three main machine learning paradigms and when is each used? | Supervised: Labeled data, predict outputs (classification, regression). Unsupervised: No labels, find patterns (clustering, dimensionality reduction). Reinforcement: Agent learns from rewards in environment (robotics, game AI). Exam tip: No labels = unsupervised. Agent + rewards = reinforcement. Labels = supervised. |
| 3 | Overfitting vs underfitting — how do you identify each from training and validation loss? | Overfitting: Training loss very low, validation loss high (large gap). Underfitting: Both training and validation loss high. Exam tip: If training accuracy is 95% but validation is 70%, that's overfitting. If both are 65%, that's underfitting. |
| 4 | L1 vs L2 regularization — what's the key difference? | L1: Adds sum of absolute weights to loss, promotes sparsity (many weights → 0). L2: Adds sum of squared weights, promotes small weights but rarely exactly 0. Exam tip: L2 is more common. Both prevent overfitting by penalizing large weights. |
| 5 | Dropout rate of 0.5 during training — what happens at inference time? | Dropout is turned OFF (rate = 0). All neurons are active. Outputs are scaled to account for training-time dropout. Exam tip: Dropout is ONLY active during training, never during prediction. Keeping it on would make predictions random. |
| 6 | ReLU activation function — formula and why it's used in hidden layers? | ReLU(x) = max(0, x). Used because: (1) Computationally fast, (2) Reduces vanishing gradient problem vs sigmoid/tanh, (3) Induces sparsity (negatives → 0). Exam tip: ReLU in hidden layers, sigmoid/softmax in output layer for classification. |
| 7 | Sigmoid activation — output range and primary use case? | σ(x) = 1/(1+e^-x). Output range: (0, 1). Use: Binary classification output layer (interpreted as probability of positive class). Exam tip: Sigmoid for binary output, softmax for multi-class output, ReLU for hidden layers. |
| 8 | What is an embedding and why does it matter for LLMs? | Embedding: Dense vector representation (e.g., 768 dimensions) that encodes semantic meaning. Words with similar meanings have similar embeddings (high cosine similarity). LLMs: Transform text to embeddings to capture context and relationships. Exam tip: Embeddings enable semantic search, similarity, and transfer learning. |
| 9 | Cross-entropy loss vs mean squared error (MSE) — when to use each? | Cross-entropy: Classification (outputs probabilities). MSE: Regression (outputs continuous values). Exam tip: If predicting categories/classes → cross-entropy. If predicting numbers (price, temperature) → MSE. Using wrong loss for task type is exam trap. |
| 10 | Gradient descent — what is it optimizing and how? | Optimizes model weights by minimizing loss function. Calculates gradient (derivative) of loss with respect to weights, updates weights in opposite direction of gradient. Exam tip: Learning rate too high → unstable. Too low → slow convergence. Adam optimizer is common choice. |
| 11 | Backpropagation — what is it and when does it happen? | Algorithm to calculate gradients of loss with respect to each weight in neural network, working backwards from output to input layers. Happens during training after forward pass computes loss. Exam tip: Forward pass = prediction. Backward pass = gradient calculation for weight updates. |
| 12 | Common embedding dimensions for modern LLMs? | BERT-base: 768. BERT-large: 1024. GPT-3: 12288. Sentence transformers: 384-768. Exam tip: Higher dimensions capture more nuance but require more compute. 768 is common default. Cosine similarity measures semantic closeness between embeddings. |
