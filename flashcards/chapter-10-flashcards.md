## Chapter 10: Full NCA-GENL Exam Simulation and Test-Taking Strategy — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | NCA-GENL exam format and duration? | 50-51 multiple-choice questions, 60 minutes, online remote-proctored. Single answer per question. Passing score ~70% (36+ correct). Exam tip: 1.2 minutes per question average - aim for 1 minute to bank time for review. |
| 2 | Time management strategy: What to do if a question takes >90 seconds? | Flag it and move on. Come back at end with banked time. Don't let one hard question consume 3-4 minutes early on. Exam tip: Answer all easy questions first (bank ~10-15 minutes), then tackle flagged questions. |
| 3 | BLEU vs ROUGE - which for translation, which for summarization? | BLEU = translation (measures n-gram precision). ROUGE = summarization (measures recall). Exam tip: BLEU has 'B' for Bilingual (translation). ROUGE has 'R' for Recall (summarization needs to recall key points). |
| 4 | Decoder-only vs encoder-decoder models - which for dialogue generation? | Decoder-only (e.g., Llama, GPT) for dialogue/text generation. Encoder-decoder for translation or summarization. Exam tip: Decoder-only models are autoregressive (predict next token) - ideal for open-ended generation like chatbots. |
| 5 | Temperature parameter - effect on output diversity? | Higher temperature (0.8-1.0) = more random/creative. Lower temperature (0.1-0.3) = more deterministic/focused. Temperature=0 = greedy (always pick highest probability). Exam tip: Temperature is THE parameter for creativity control. |
| 6 | Training loss decreases, validation loss increases - what's the problem? | Overfitting. Model memorizing training data, not generalizing. Solution: early stopping or regularization. Exam tip: Diverging train/val loss = overfitting. Both high = underfitting. Both decreasing = good training. |
| 7 | RLHF process - correct order of steps? | 1) Pre-train base model, 2) Supervised fine-tuning (SFT) on demos, 3) Train reward model on human preferences, 4) Use PPO to optimize against reward model. Exam tip: SFT before reward model (need outputs to rank). |
| 8 | NVIDIA NIM vs NeMo - which is for deployment, which for training? | NIM = deployment/inference (production-ready microservices). NeMo = training/development (framework for building models). Exam tip: NIM for 'production', NeMo for 'custom training'. |
| 9 | Riva ASR vs Riva TTS - which direction is each? | ASR (Automatic Speech Recognition) = audio → text (transcription). TTS (Text-to-Speech) = text → audio (synthesis). Exam tip: ASR for call transcription, TTS for voice assistants speaking. |
| 10 | RAG system with 10 million documents - which NVIDIA component? | NeMo Retriever (handles embeddings, vector DB, semantic search at scale). NOT brute-force LLM search (too slow/expensive). Exam tip: Retriever for large-scale document search in RAG. |
| 11 | Exam question has 'MOST appropriate' with 2 valid options - how to choose? | Choose most cost-effective, simplest, aligned with best practices. Avoid over-engineering. Exam tip: NVIDIA exams favor practical enterprise solutions over complex/advanced tech for tech's sake. |
| 12 | Common exam traps - what keywords to watch for? | Watch for: 'NOT', 'BEST', 'MOST', 'LEAST'. These change the question entirely. Exam tip: Read carefully, underline these words mentally. 'Which is NOT' trips up candidates rushing. |
