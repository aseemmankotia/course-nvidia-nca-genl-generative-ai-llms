# Chapter 5 Lab: Data Preprocessing, Feature Engineering, Analysis and Visualisation

**Estimated time:** 20 minutes

## Exercise

Preprocess a raw text dataset: clean HTML tags, lowercase, tokenise with a subword tokenizer (e.g. GPT-2); plot token-length distribution and identify outliers; visualise class imbalance in a sentiment dataset; apply padding and attention masks for a batch; generate a word cloud and a t-SNE plot of embeddings

## Key takeaway

Effective LLM workflows start with clean, tokenised, and well-analysed data; subword tokenisation handles large vocabularies, and class weighting or augmentation addresses imbalance.
