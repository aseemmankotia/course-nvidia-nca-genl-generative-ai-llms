# Chapter 6 Lab: Experimentation and Evaluation

**Estimated time:** 18 minutes

## Exercise

Compute perplexity of a language model on a held-out test set; calculate BLEU and ROUGE scores for a summarisation task using reference summaries; run an A/B test comparing two prompts (measure success rate); use an LLM-as-judge (e.g. GPT-4 API) to score outputs on a 1-5 scale; interpret results and decide which version wins

## Key takeaway

Evaluate LLMs with perplexity (next-token prediction), BLEU/ROUGE (reference-based tasks), human ratings, and LLM-as-judge; A/B tests and ablation studies isolate what drives performance.
