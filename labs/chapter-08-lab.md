# Chapter 8 Lab: LLM Integration and Deployment—Part 2: The NVIDIA Software Stack

**Estimated time:** 20 minutes

## Exercise

Conceptual lab: read NVIDIA NIM documentation and identify which pre-built container to use for a LLaMA-2 deployment; review a Triton model config file and explain dynamic batching settings; compare TensorRT-LLM optimised model latency vs unoptimised Hugging Face model (using published benchmarks or a provided chart); discuss GPU memory requirements for a 7B vs 70B model and when multi-GPU is needed

## Key takeaway

NVIDIA's GenAI stack (NeMo, NIM, Triton, TensorRT-LLM) provides end-to-end tools for training, optimising, and deploying LLMs at scale with GPU acceleration and reduced latency.
