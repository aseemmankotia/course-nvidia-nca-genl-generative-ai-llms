# Chapter 3 Lab: Prompt Engineering

**Estimated time:** 20 minutes

## Exercise

Write zero-shot and few-shot prompts for a classification task (e.g. sentiment analysis); compare outputs; rewrite with chain-of-thought reasoning; experiment with temperature 0, 0.7, and 1.5 on the same prompt; observe how top-p=0.9 changes output diversity

## Key takeaway

Effective prompts use zero-shot for simple tasks, few-shot for edge cases, and chain-of-thought for reasoning; control output with temperature (randomness) and top-p (sampling diversity).
