# Chapter 2 Lab: Transformer Architecture and Large Language Models

**Estimated time:** 18 minutes

## Exercise

Tokenise a sentence with a Hugging Face tokenizer (e.g. GPT-2 or BERT); inspect token IDs and special tokens; visualise attention weights from a pre-trained transformer layer; compare encoder-decoder vs decoder-only model outputs on the same input

## Key takeaway

Transformers use self-attention (query, key, value) and positional encoding to process sequences in parallel; decoder-only models generate text autoregressively, encoder-decoder models handle input-to-output transformations.
