# Chapter 4 Lab: Alignment, Safety and Responsible AI

**Estimated time:** 18 minutes

## Exercise

Run a base LLM and an RLHF-tuned version (e.g. GPT-3.5 vs GPT-3.5-turbo-instruct) on the same harmful prompt; observe output differences; write a prompt that attempts to bypass a safety filter; propose guardrails (input keyword filter, output toxicity classifier); identify a hallucination in model output and verify with a fact-check

## Key takeaway

Alignment techniques like RLHF and instruction tuning make LLMs safer and more useful; guardrails, grounding (RAG), and monitoring mitigate bias, toxicity, hallucination, and adversarial attacks.
