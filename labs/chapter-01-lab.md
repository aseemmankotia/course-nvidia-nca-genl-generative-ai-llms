# Chapter 1 Lab: Machine Learning and Neural Network Fundamentals

**Estimated time:** 15 minutes

## Exercise

Convert text into word embeddings using a pre-trained model (e.g. Word2Vec or a simple Hugging Face tokenizer); visualise embeddings in 2D with PCA or t-SNE; compare cosine similarity of similar vs dissimilar words

## Key takeaway

LLMs build on core ML: supervised pretraining on massive text, embeddings to represent tokens as dense vectors, and gradient descent to learn patterns—overfitting is controlled by scale and regularisation.
